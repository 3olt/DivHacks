# context.md vs the backend spec: conflicts (Phase 0)

The backend follows the spec (`shared/contracts.ts` + `docs/API.md`). `context.md` is owned by the frontend teammate and is not edited here. Each row says what we do and what, if anything, the frontend should change.

## New in commit a3795b4 ("Add iMessage sign-up with Photon Spectrum")

| Severity | Topic | Issue | Resolution / frontend action |
|---|---|---|---|
